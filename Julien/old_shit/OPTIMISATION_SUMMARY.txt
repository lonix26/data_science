CLÉS DE SUCCÈS :
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  QuantileTransformer (Clé majeure - gain +12%)
    • Remplace RobustScaler
    • Transforme les données en distribution normal
    • Améliore la convergence de Lasso
    • Gère mieux les valeurs extrêmes

2️⃣  Alpha fine-tuning (Gain +8-9%)
    • Augmenter la résolution des alphas testés
    • De 40 à 500-1000 valeurs testées
    • CV=5 suffit (pas de gain avec CV=10)

3️⃣  Target Encoding (Gain +3-4%)
    • Intégration de sklearn.preprocessing.TargetEncoder
    • Cross-validation interne (cv=5)
    • Meilleur que One-Hot pour 43 variables catégoriques

4️⃣  Lasso Regression (Gain +5% vs Ridge)
    • L1 regularization sélectionne 55/79 features
    • Élimine 30.4% des variables inutiles
    • Alpha optimal : 0.000340 (très petit = régularisation faible)

RECOMMANDATIONS POUR ALLER PLUS LOIN (Beyond 0.125) :
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Niveau Facile (Gain attendu : +1-2%) :
  □ Feature engineering
    • Log transformations des variables très skewées
    • Ratios (Price/m², Price/rooms, etc.)
    • Polynomiales pour top 5 features

  □ Ensembling
    • Moyenne pondérée : Lasso + Ridge + ElasticNet
    • Stacking avec métamodèle

Niveau Moyen (Gain attendu : +2-3%) :
  □ Hyperparameter tuning fin
    • GridSearchCV ou optuna pour tous les paramètres
    • Tuner le smoothing de TargetEncoder
    • Tester d'autres distributions (QuantileTransformer)

  □ Feature selection avancée
    • Recursive Feature Elimination (RFE)
    • Analyse de multicollinéarité (VIF)
    • Chi² pour variables catégoriques

Niveau Difficile (Gain attendu : +3-5%) :
  □ Gradient Boosting (XGBoost, LightGBM)
    • Plus flexible que Lasso
    • Gère interactions automatiquement
    • RMSE attendu : 0.10-0.11

  □ Neural Networks
    • Deep Learning avec Keras/PyTorch
    • Architecture : dense layers + dropout
    • Plus de données utile pour NNs
